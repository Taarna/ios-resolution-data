# ios-resolution-data

Data for the web page [iOS Display](https://ios-resolution.info?utm_source=github). It's a simple page that lists display specifications for iPhones, iPads, iPods, and Apple Watches.

This project came out of me asking various LLMs how they would build a minimal web page in 2025. The initial results were bloated React/Node.js setups with lots of unused components and weird project configurations. With some prompt tweaking and clearer instructions, I got them to produce a simpler solution that looks decent enough and isn't overly complicated.

I often refer to a similar well known page when testing on different screen sizes, and figured this was a good chance to try and produce my own version.

Most of the data in the file was sourced from Wikipedia. I calculated the missing pieces myself.
